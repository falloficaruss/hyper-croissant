The Story

Chess amateurs can run strong engines but often don't understand why a move is best. Existing tools show raw evaluation numbers and principal variations — useful for grandmasters, but meaningless for club players trying to improve.

Oropis bridges this gap with a fundamentally different approach: a symbolic chess intelligence layer that understands positions using pure chess logic, with an LLM used only as a translator to turn structured analysis into clear, level-appropriate explanations.

The key insight: the LLM is the last component, not the first. By building a deterministic analysis pipeline in Rust, Oropis ensures that every explanation is grounded in actual chess concepts — not hallucinated variations.
